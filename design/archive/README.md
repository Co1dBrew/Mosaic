# 旧 IA 对照屏归档（D-08）

本目录存放已从生产 Figma 文件中移除的「现状对照屏」。

## 归档内容

| 文件 | 内容 |
|---|---|
| `legacy-screens.js` | ①现状首页（文件夹列表）· ③现状卡片列表内摘要展开 · ⑦现状编辑器＋添加内容菜单 —— 三屏的生成代码 |
| `../mockup.html` | 同样三屏的 HTML 高保真渲染（现状 vs 改后并排对照），含浅色/深色 |

## 为什么不是 PNG

原计划导出 PNG 归档。实际执行时发现**做不到**：

- Dev Mode MCP 是只读的，能截图给我看，但无法把图片字节写到磁盘
- Figma Plugin API 有 `exportAsync()`，但插件沙箱没有文件系统访问权限

因此改为归档**生成代码 + 已有的 HTML 渲染**。二者合起来完整保留了论证依据，
且比 PNG 更有价值：代码可重新生成，HTML 可直接在浏览器打开对照。

**如果你需要 PNG**：在 Figma 里选中对应画板 → 右侧面板 Export → PNG，2 次点击。
这一步必须由你手动完成。
